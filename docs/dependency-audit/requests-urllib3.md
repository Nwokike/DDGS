# Dependency audit: requests + urllib3 (vs primp + httpx)

Date: 2026-09-29 · Installed: `requests 2.34.2`, `urllib3 2.8.0` · App: ddgs-app 2.0.2
Consumer note: the grep for `requests`/`urllib3` in `src/` hit only English prose
("automated requests", "direct fallback requests") — zero `import requests` /
`import urllib3` in `src/` or `tests/`. The app's own HTTP is **primp**

## 1. COMPLETE API INVENTORY (one line per capability)

### requests
- `Session` (`sessions.py`): cookie persistence + per-session headers/auth/params/proxies/hooks/verify/cert/stream/trust_env/max_redirects(30), usable as context manager, `mount(prefix, adapter)` with longest-prefix-wins ordering.
- `Session.request(method, url, params/data/json/headers/cookies/files/auth/timeout/allow_redirects/proxies/hooks/stream/verify/cert)` — builds `Request`, merges session settings, sends, follows redirects into `r.history`.
- Verb shorthands — `get/options/head/post/put/patch/delete` on `Session` and top-level `api.py` (top-level opens a throwaway `Session` per call: no pooling, use `Session` for repeats; `head()` defaults `allow_redirects=False`).
- Hooks (`hooks.py`): only event is `"response"`; `register_hook`/`deregister_hook` on `Request`/`PreparedRequest`, `dispatch_hook` applies callables in order, return value replaces data if not None.
- `HTTPAdapter(pool_connections=10, pool_maxsize=10, max_retries=0, pool_block=False)` (`adapters.py`) — wraps a urllib3 `PoolManager`; `init_poolmanager`, `proxy_manager_for`, `cert_verify`, `build_response`, `request_url`, `add_headers` (no-op hook for subclasses), `send`, `close`.
- `max_retries` semantics: int counts only connect/DNS/timeout retries (never resends once bytes reached server); pass urllib3 `Retry` for granular control; `get_connection()` is deprecated since 2.32.2 in favour of `get_connection_with_tls_context()`.
- Auth (`auth.py`): `HTTPBasicAuth(user, pass)` / `(user, pass)` tuple sets `Authorization: Basic`; `HTTPProxyAuth` sets `Proxy-Authorization`; `HTTPDigestAuth` is stateful per-thread (nonce/cnonce/nc, MD5/MD5-SESS/SHA/SHA-256/SHA-512, auto-replays on 401 via response hooks, rewinds body).
- Response API (`models.py`): `.status_code/.headers(CaseInsensitiveDict)/.url/.encoding/.history/.reason/.cookies/.elapsed/.request`, `.content` (bytes, cached), `.text` (header charset → chardet/charset-normalizer fallback), `.json(**loads_kwargs)`, `.iter_content(chunk_size, decode_unicode)`, `.iter_lines(chunk_size, decode_unicode, delimiter)` (not re-entrant), `.links` (parsed `Link` header), `.ok`/bool (status < 400, NOT "== 200"), `.is_redirect/.is_permanent_redirect/.next`, `.raise_for_status()`, `.close()`/`release_conn()`, `.raw` (urllib3 response, needs `stream=True`).
- `Request` vs `PreparedRequest`: `Request(method, url, headers/files/data/json/params/auth/cookies/hooks)` + `.prepare()`; `PreparedRequest.prepare_*` stages (method/url/headers/cookies/body/auth/hooks), `.copy()` used internally per redirect; never pass a bare `Request` to `send()`.
- Bodies: dict/list-of-tuples → form-encoded; `json=` → `application/json` (allow_nan=False); `files=` 2/3/4-tuples `(filename, fileobj[, content_type[, headers]])` → multipart via urllib3 `encode_multipart_formdata`; file-likes/generators stream with `Content-Length` or chunked fallback; non-GET/HEAD without body gets `Content-Length: 0`.
- Timeouts: **scalar float = both connect and read** (`Timeout(connect=t, read=t)`); **tuple `(connect, read)`** splits them; may also pass a urllib3 `Timeout`; `None` = wait forever (default when omitted) — the classic pitfall is assuming a default timeout exists.
- SSL/verify: `verify=True` (default, certifi bundle via `certs.where()`), `verify=False` disables cert+hostname checks (MitM-able, dev only), `verify="path"` uses custom CA bundle/dir; `cert="file.pem"` or `("cert","key")` for mTLS; env honoured when `trust_env=True` (`REQUESTS_CA_BUNDLE`/`CURL_CA_BUNDLE`, proxies, netrc).
- Redirects: `resolve_redirects` follows 301/302/303/307/308 (301-POST→GET, 302→GET, 303→GET like browsers; 307/308 preserve method), strips `Authorization` on cross-host/scheme/port change, re-resolves proxies/netrc per hop, rewinds bodies, caps at `max_redirects=30` (`TooManyRedirects`).
- Proxies/env: `trust_env=True` merges `HTTP(S)_PROXY`/`ALL_PROXY`/`NO_PROXY` (CIDR + suffix match, Windows registry bypass), per-host `scheme://host` keys beat bare schemes; `should_bypass_proxies`/`get_environ_proxies`/`select_proxy`/`resolve_proxies` in `utils.py`.
- Structures (`structures.py`): `CaseInsensitiveDict` (case-insensitive lookup, preserves last-set case) and `LookupDict`-based `codes` (`status_codes.py`: `codes.ok/created/found/too_many/not_found/teapot…`, attr or item access, upper+lowercase aliases).
- Cookies (`cookies.py`): `RequestsCookieJar` (dict-like over `http.cookiejar`), `cookiejar_from_dict`/`extract_cookies_to_jar`/`get_cookie_header`/`remove_cookie_by_name`/`MockRequest` bridge.
- Utils (`utils.py`): `default_headers()` (python-requests UA, keep-alive), `parse_header_links`, `guess_json_utf` (BOM/null-count sniffing), `requote_uri`/`unquote_unreserved`, `prepend_scheme_if_needed`, `get_auth_from_url`, `super_len`, `iter_slices`, `atomic_open`, netrc helpers, `check_header_validity` (rejects header injection).
- Exceptions (`exceptions.py`, all under `RequestException(IOError)` carrying `.request/.response`): `HTTPError/ConnectionError/ProxyError/SSLError/Timeout(→ConnectTimeout,ReadTimeout)/URLRequired/TooManyRedirects/MissingSchema/InvalidSchema/InvalidURL(/InvalidProxyURL)/InvalidHeader/ChunkedEncodingError/ContentDecodingError/StreamConsumedError/RetryError/UnrewindableBodyError/InvalidJSONError/JSONDecodeError`, warnings `FileModeWarning/RequestsDependencyWarning`.
- Compat/shims: `compat.py` (urllib3-major flag, chardet-vs-charset_normalizer resolver, py2 leftovers), `packages.py` (aliases `requests.packages.urllib3` → real urllib3), `help.py` (`requests.help.info()` bug-report dict), `_internal_utils.py` (header validators, `to_native_string`).

### urllib3 (v2.8.0)
- `PoolManager(num_pools=10, headers=None, **connection_pool_kw)` (`poolmanager.py`): LRU pool cache keyed by scheme/host/port/timeout/retries/SSL/proxy (PoolKey), `connection_from_host/url/context/pool_key`, `urlopen` handles cross-host redirects itself (303→GET + body drop, strips forwarded auth headers), `clear()`, context-manager support.
- `ProxyManager(proxy_url, proxy_headers, proxy_ssl_context, use_forwarding_for_https=False, proxy_assert_hostname/fingerprint)` + `proxy_from_url()` — CONNECT tunnels for HTTPS, absolute-form for plain HTTP, SOCKS via `contrib/socks.py` (socks4/4a/5/5h + user/pass, needs PySocks).
- `HTTPConnectionPool/HTTPSConnectionPool(host, port, timeout, maxsize=1, block=False, retries=Retry.DEFAULT, …)` (`connectionpool.py`): LIFO queue of keep-alive conns, `block=True` raises `EmptyPoolError`/`FullPoolError` instead of growing, `_validate_conn`, `is_same_host`, `urlopen`, `close`.
- `RequestMethods.request(method, url, body/fields/headers/json)` (`_request_methods.py`): GET/HEAD/DELETE/OPTIONS encode `fields` into URL, others into body (multipart default, `encode_multipart=False` → urlencoded, `multipart_boundary` settable); top-level `urllib3.request()` shares a global `PoolManager` (side effects shared — prefer your own instance).
- Streaming (`response.py`): `BaseHTTPResponse/HTTPResponse` with `preload_content` (buffer whole body) / `decode_content` (gzip/deflate/brotli/zstd by header) flags, `.stream(amt)/.read(amt)/.read_chunked()/.data/.json()/.url/.retries`, `.drain_conn()` to return conn to pool; 64 KiB read chunks; chunk-size lines capped like stdlib against memory-exhaustion.
- `Retry(total/connect/read/redirect/status/other, allowed_methods, status_forcelist, backoff_factor, backoff_max=120, backoff_jitter, raise_on_redirect/raise_on_status, respect_retry_after_header, remove_headers_on_redirect, retry_after_max)` (`util/retry.py`): immutable-ish (each attempt returns new object), failures surface as `MaxRetryError`; `Retry.DEFAULT` retries 3×.
- `Timeout(connect, read, total)` (`util/timeout.py`): `total` caps whole attempt with leftover logic, `None` disables that leg; DNS resolution ignores socket timeout; read timeout is between-bytes, not whole-response.
- TLS (`util/ssl_.py`): `create_urllib3_context(ssl_version, cert_reqs=CERT_REQUIRED, ciphers, minimum/maximum TLSVersion…)` floors TLS at 1.2, ALPN `http/1.1`; needs OpenSSL 1.1.1+; `assert_hostname/assert_fingerprint` pinning supported at pool level.
- Multipart (`filepost.py`/`fields.py`): `encode_multipart_formdata(fields, boundary=None)` with random hex boundary, `RequestField(name, data, filename, headers)` + `guess_content_type` (mimetypes); `format_header_param_rfc2231` deprecated insecure (FutureWarning, gone in v3).
- URL (`util/url.py`): RFC-3986 `parse_url` → `Url(scheme, auth, host, port, path, query, fragment)` with IDNA, IPv4/IPv6+zone handling, normalisation; `LocationParseError/LocationValueError/URLSchemeUnknown`.
- Exceptions (`exceptions.py`): `MaxRetryError/HostChangedError/TimeoutError(→ReadTimeoutError,ConnectTimeoutError→NewConnectionError→NameResolutionError)/EmptyPoolError/FullPoolError/ClosedPoolError/SSLError/ProxyError/DecodeError/ProtocolError(=ConnectionError alias)/ResponseError/InvalidHeader/HeaderParsingError/LocationParseError/UnrewindableBodyError/IncompleteRead/InvalidChunkLength` + warnings `SecurityWarning/InsecureRequestWarning/NotOpenSSLWarning/SystemTimeWarning/InsecurePlatformWarning/DependencyWarning`.
- HTTP/2 (`http2/`): **not built in** — opt-in via `inject_into_urllib3()` which monkey-patches `HTTPSConnection` to `HTTP2Connection` and ALPN to `h2`, requires `h2` 4.x, probe cache per host:port; emscripten target auto-injects its own fetch backend (`contrib/emscripten/`).
- `contrib/pyopenssl.py`: legacy pyOpenSSL injection, explicitly no longer recommended (stdlib `ssl` does SNI everywhere now); `util/ssl_match_hostname.py`, `util/ssltransport.py` (TLS-in-TLS), `util/wait.py` (`wait_for_read/write`), `util/proxy.py` (tunnel decision), `util/response.py` (`is_fp_closed`, HEAD check), `util/connection.py` (dropped-conn detection), `_collections.py` (`HTTPHeaderDict`, `RecentlyUsedContainer`).

## 2. STRATEGIC ASSESSMENT — verdict: PURE BALLAST for app code (keep on disk, do not adopt)

Dependency chain from `uv.lock` (nothing in `[project].dependencies` references them):
- `requests 2.34.2` ← **`tiktoken 0.14.0`** (`dependencies: regex, requests` — fetches BPE ranks over HTTP on a cold cache) ← `openai` ← **`kani[openai]` (direct runtime dep)**. This is the live chain that installs requests into every environment.
- `requests` ← **`cookiecutter 2.7.1`** ← **`flet-cli 1.0.1`** ← dev-only group `flet[cli,desktop]==1.0.1` — dev-time only, never ships in the app.
- `urllib3 2.8.0` ← **only `requests`** (sole `dependencies` entry naming urllib3 in the lock). No other package touches it. `ddgs 9.16.0` needs only click/lxml/primp; `flet` runtime needs only httpx/msgpack/oauthlib/repath; `qrcode` is standalone.
- So both ride along transitively; the app itself never imports either.

Should they be USED anywhere? No — primp+httpx already cover every path, and switching would lose capabilities: primp gives browser impersonation/anti-bot (search, media, Innertube) that requests cannot do; httpx gives async + HTTP/2-off + custom transports (`ThoughtTapTransport`) that sync requests cannot do. The only honest niche would be a fire-and-forget sync one-shot inside a worker thread (e.g. update-check or license ping where the existing httpx call already exists), and that would add a third HTTP semantic for zero gain. Cookiecutter is dev-scaffolding only; qrcode does no HTTP at all.

## 3. GOTCHAS (if anyone is ever tempted)

- **Blocking sync API — NEVER call `requests.*` on the Flet UI thread**: every call blocks until connect+read timeouts expire (default = forever); always run in a worker thread/executor and marshal results back, same rule as for sync httpx.
- **Timeout tuple pitfall**: `timeout=10` sets *both* connect and read to 10 s; `timeout=(3, 15)` = 3 s connect + 15 s between-bytes read (not total time); omitting `timeout` means **no timeout at all** — pass an explicit tuple on every call.
- **`stream=False` (default) buffers the whole body** into `r.content`; for media/downloads always `stream=True` + `iter_content`, else large files OOM the app (media_downloader already does this right with primp).
- **SSL defaults**: `verify=True` via certifi is safe; `verify=False` silences only via `InsecureRequestWarning` and opens MitM — never ship it; note `core/tls.py` repairs `SSL_CERT_FILE` for httpx/certifi, requests would need the same care with custom bundles.
- **urllib3 v2 specifics**: requires OpenSSL 1.1.1+ (`NotOpenSSLWarning` otherwise); `NewConnectionError.pool` property deprecated (use `.conn`); `format_header_param_rfc2231` deprecated insecure; schemeless URLs warn `FutureWarning` (v3 will raise); `strict` param removed (FutureWarning); `Retry` with empty `allowed_methods` skips all retries in v3; HTTP/2 needs manual `inject_into_urllib3()` + `h2==4.x` (the app deliberately runs `httpx(..., http2=False)` — do not mix).
- **Session hygiene**: top-level `requests.get()` leaks pooling benefits (new Session per call); share one `Session`, `mount()` adapters for pool tuning, and `close()`/context-manage it; `Response` objects hold pooled conns until consumed or `close()`d.
